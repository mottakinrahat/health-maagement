# 🏥 AI Powered Hospital Management System

An **AI-powered online hospital management platform** that connects patients with doctors efficiently. The system uses **Artificial Intelligence** to recommend doctors based on user search interests and medical needs.

Patients can easily search doctors, check schedules, book appointments, consult through video calls, receive prescriptions online, and make secure payments using **SSLCommerz**.

---

## 🚀 Features

### 🤖 AI Doctor Recommendation
- AI analyzes patient search behavior and medical categories.
- Recommends the most suitable doctors automatically.

### 👨‍⚕️ Doctor Management
- Doctors can create and manage profiles.
- Set available consultation schedules.
- Manage appointments.
- Provide digital prescriptions.

### 👤 Patient Management
- User registration and authentication.
- Search doctors by specialty.
- View doctor profiles and availability.

### 📅 Appointment Booking
- Online appointment booking.
- Real-time doctor schedule checking.
- Appointment history tracking.

### 🎥 Video Consultation
- Secure **video call consultation** between doctor and patient.
- Remote healthcare services.

### 📝 Online Prescription
- Doctors can create prescriptions digitally.
- Patients can download or view prescriptions.

### 💳 Secure Payment
- Integrated **SSLCommerz Payment Gateway**.
- Secure online payment for doctor consultations.

### 📊 Dashboard System

#### Patient Dashboard
- Book appointments
- View prescriptions
- Payment history

#### Doctor Dashboard
- Manage schedules
- View patient appointments
- Provide prescriptions

#### Admin Dashboard
- Manage doctors
- Manage users
- Monitor appointments and transactions
